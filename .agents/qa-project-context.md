## Product

- **Name:** CryptoTrack
- **One-liner:** A cryptocurrency portfolio tracker: users log in, maintain a portfolio of coins (buy/sell holdings), track allocation and profit/loss against live market data, and keep a watchlist.
- **Type:** Consumer web app (SaaS-style), single-page frontend + REST API backend.
- **URLs:**
  - Development frontend: http://localhost:5173 (Vite dev server)
  - Development API: http://localhost:3000 (Express)
  - Production frontend: https://cryptotrack-ultimez.vercel.app (per `Client/vercel.json`)
  - Production API: same Express service; CORS default origin points at the Vercel URL
- **Key user journeys (test priorities):**
  1. Visitor signs up / logs in and lands on `/dashboard`.
  2. Authenticated user views portfolio summary: Current Value, Total Investment, profit/loss %.
  3. User adds a coin to the portfolio (buy price + amount) and sees charts/table/totals update.
  4. User sells/removes a coin from the portfolio (including selling more than owned → must be blocked).
  5. User toggles coins in/out of the watchlist from the dashboard/portfolio table.
  6. User browses live market data on `/` (home, top coins, search).
  7. User exports portfolio details to CSV and PDF from the dashboard.
  8. User switches display currency (USD/EUR/…) and toggles dark mode.
  9. Unauthenticated user requesting `/dashboard` or `/watchlist` is redirected to `/login`.
  10. User logs out and can no longer reach protected routes.

## Risk Areas

| Area | Risk Level (Impact × Likelihood) | Business Impact | Notes |
|---|---|---|---|
| Auth & route guards (JWT in localStorage, `/dashboard` → `/login` redirect) | **Critical** (high × medium) | Broken guard exposes empty screens or locks users out entirely | Guard logic duplicated per-route in `App.jsx`; no token expiry handling client-side (24 h JWT, no refresh) — expired token means API 401s with no redirect. |
| Portfolio math & sell validation (totals, P/L %, sell > owned) | **Critical** (high × medium) | Wrong money numbers destroy trust in a finance app | Split across client (`Dashboard.jsx`, `Form.jsx`) and server (`/portfolio/update`); rounding via `/currency[1]`; server is the final authority but client shows stale totals. |
| CoinGecko dependency (market prices, home/top coins) | **Important** (high × high likelihood of flakiness) | Rate limits / outages blank the charts and tables | Direct client-side fetch, no cache, no retry, error state renders generic text; CORS/rate-limit 429s hit real users. |
| Export to CSV / PDF (jspdf, autotable, fonts) | **Monitor** (medium × medium) | Broken exports; heavy client bundle | Client-side generation, untested formatting with dynamic currency. |
| Currency & dark-mode state | **Monitor** (medium × high) | Cosmetic but visible regressions | `CurrencyContext` defaults to `["USD", 1]`, not persisted (refresh resets currency); conversion math lives in `Form.handleSubmit`. |
